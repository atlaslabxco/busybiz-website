# Busy Biz Solution — redesigned website

Static HTML/CSS/JavaScript site for GitHub Pages. No install or build step required.

Read ATLAS-HANDOFF.md before publishing. Enquiry delivery is intentionally unconfigured in config.js pending the business recipient/endpoint. The website is a review draft, not yet live.

Preview: `python3 -m http.server 8080`, then open http://localhost:8080.

Homepage: index.html, styles.css, script.js, config.js.
Shared demo appearance/navigation: game-theme.css, game-shell.js.
All six original HTML game URLs are preserved in games/.

The source uses Google Fonts, with system fallbacks. The campaign image is generated concept artwork. All game rewards are demonstrations, not redeemable offers.
